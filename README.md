# 🟡 Pac-Man (Web Edition)

I created a browser-based version of the classic **Pac-Man** arcade game from scratch using plain **HTML, CSS and JavaScript**. No game engines, no frameworks— pure web code to bring back the nostalgia of dodging ghosts grabbing power pellets and chasing high scores.

👉 **[Play it in your browser](#)** *(Swap this link out once you host it!)*

---

## What's Inside?

* **The Classic Maze Loop:** Eat all dots to board while avoiding four ghosts.

* **Different Ghost Behaviors:** Each ghost hunts Pac-Man down a little differently—some chase Pac-Man directly while others try to cut Pac-Man off or wander.

* **Power Pellets & Combos:** Grab a flashing dot to turn ghosts blue and eat ghosts for bonus points (`200` `400` `800` and `1600`).

* **Side Warp Tunnels:** Slip through the right edges of screen to escape tight spots.

* **Pure Vanilla Code:** Everything runs on HTML, CSS and JS without any external libraries.

## Running It on Your Computer

Since there are no dependencies or build steps getting it running takes ten seconds:

1.. Clone this repo:

```bash

git clone https://github.com/Muhammed-Nafy-KK/pacman.git

```

2. Open the folder and double-click `index.html` to launch Pac-Man in Chrome, Firefox, Edge or Safari.
